# Security policy

Relay is under active development and is not yet suitable for production or public internet exposure. Please do not include secrets, private keys, or personal data in reports.

This repository does not yet publish a verified private security contact. Do not post exploit details in a public issue. If GitHub private vulnerability reporting is enabled for the repository, use that channel; otherwise contact the repository maintainers privately and ask for a secure reporting route before sending sensitive details. Give maintainers a reasonable opportunity to investigate and prepare a fix before public disclosure. Do not test against systems you do not own or have permission to assess.

No supported release line has been established yet. Security fixes will be documented in the changelog when releases begin.
